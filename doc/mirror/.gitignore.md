# Python 环境与生成文件

**文件范围**

- `**/__pycache__/**` 忽略各层级缓存目录内的文件，例如导入模块时生成的字节码。规则由 Git 读取[^ignore]。
- `/.venv/` 忽略在库源码根创建的项目虚拟环境。[建立环境并运行演示](../integration.md#体验)
- `/build/` 和 `/*.egg-info/` 忽略从当前源码安装时生成的构建文件及包元数据[^ignore]。

**检查示例**

- 在仓库根执行。输出列出的路径表示它匹配当前忽略规则，示例文件可以尚未生成。

```bash
git check-ignore --no-index .venv/bin/python src/__pycache__/console.cpython-312.pyc
```
